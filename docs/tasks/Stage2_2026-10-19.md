## 1. 论文方法为何这样选：固定，不再变

### 1.1 ICASSP 2026 原公式

论文 *Robustifying Graph Laplacian Regularization Against Edge Weight Uncertainties: An Infimal Convolution Approach*（用户上传 5 页 PDF），Section 3 Eq.(8)/(9)/(12)。定义每个无向边仅一份的关联矩阵 `D∈R^{m×N}`、边权正对角 `W`、`α∈(0,1)`, `β=1−α`：

- **IC8**：`min_{u,p} α||p||₁ + β|| sqrt(W) D u − p||₂²`。
- **IC9**：`min_{u,p} α||p||₁ + β|| Dᵀ(W D u − p)||₂`，**最后这个节点范数不平方**。
- **论文原恢复约束**：`||Φu−v||₂ ≤ r`，以及 `μ_min≤u_i≤μ_max`。本实验 `Φ=I`, `v` 为 chart 的一个坐标；`r` 是预注册的 GT-free movement allowance，不是假冒已知高斯噪声标准差。

对照定义：`IC8-P` 和 `IC9-P` 对 x、y **分别求解上述标量论文问题**；不添加导师的二次 fidelity。IC8 减去辅助变量后为作用于 `sqrt(w_e)*(Du)_e` 的 Huber；不得用 `w_e*Huber((Du)_e)` 代替。**IC9 不是 Huber**，也不能用逐边的 IRLS 代替 `Dᵀ q`。

### 1.2 Framelet TPAMI 2024 原公式与 Edge 分支

Zhou 等 *Graph Denoising With Framelet Regularizers*（arXiv:2111.03264v1；官方 GitHub `bzho3923/GNN_DoT`）。符号用 `U` 代表恢复信号，`S` 代表图自表达关系（不要把 S 与精修 chart Z 混用）：

- **Node-only，Eq.(15)**：`min_U 1/2||U−Y||²_{2,G} + ν || W_F U ||_{1,G}`，按作者高通 framelet bands 与 degree-weighting 实现，x/y 各自 L1；ADMM。
- **Self-expression regularizer，Eq.(5)**：`min_{S,E} ||S||₁ + ||E||_{2,1,G} s.t. U=SU+E, diag(S)=0`。这是**固定 U 学习自表达关系的结构拟合问题**，不输出 denoised U，不能称作论文的 Edge denoising ablation，也不是自动去除有害无线边。
- **论文 Edge denoising ablation，Eq.(17)**：`min_{U,S,E} ||S||₁ + λ₁||E||_{2,1,G} + λ₂/2||U−Y||²_{2,G}`，`s.t. diag(S)=0, U=SU+E, S1=1`。作者 `EdgeDenoisingADMM` 实现的是这一类同时更新 U/S/E 的问题。
- **完整 DoT，Eq.(6)**：`min_{U,S,E} ||νW_F U||_{1,G} + ||S||₁ + λ₁||E||_{2,1,G} + λ₂/2||U−Y||²_{2,G}`, `s.t. U=SU+E, diag(S)=0, S 1=1`。完整联合问题非凸。作者源码 `denoising_filters.py::{NodeDenoisingADMM,EdgeDenoisingADMM,BregmanADMM}`。

**为什么 Edge 必须检查但不能直接上 full-N 原式**：作者 dense `S` 和多个矩阵相乘，单个 `20997×20997 float32` 约 `1.64 GiB`（作者代码可能需要多份及稠密求解）；并且 `U` 只有二维，若不加无线先验，`SU≈U` 可能是简单的几何重心插值，不等于恢复真实邻接。在本实验中必须分别执行 Eq.(5) 结构拟合诊断、Eq.(17) Edge denoiser 和 Eq.(6) Full DoT 的小图机制 sanity；只有通过 gate 才进行 full-N `SparseDoT`。

## 4. 统一数学定义和求解器：IC

固定 `D`/`W` 按论文约定。**冻结执行：所有 IC 统一使用 `W_IC = W / mean(W_e)`（只对无向正边求均值）**，用于消除当前图整体权重尺度对 α 含义的任意影响；图结构和边权相对比率不变。原 S2-J/S2-CG 仍使用原 W，不改导师目标。manifest 同时保存原/归一化 W 统计与变换；不将图权按 GT 重新调整。

### IC8-P & IC9-P（论文形式移植）

对于 `c∈{0,1}`，`x=X[:,c]`，设 `t=η||x−mean(x)||₂`；盒 `min(x)-0.5 span(x) ≤u_i≤ max(x)+0.5 span(x)`，若坐标极窄则按统一 epsilon 处理；保留其存在但记录 active count。

- `IC8-P`: `min_{u,p} α||p||₁+β||sqrt(W)Du−p||₂²  s.t. ||u−x||₂ ≤ t, u∈box`。
- `IC9-P`: `min_{u,p} α||p||₁+β||Dᵀ(WDu−p)||₂  s.t. ||u−x||₂ ≤ t, u∈box`。

**固定参数**：`α∈{0.2,0.5,0.8}`；`η∈{0.5 δ0, 1.0 δ0, 1.5 δ0}`，其中 `δ0 = ||Z_B0+S2-J−Y_B0||F / ||Y_B0−mean(Y_B0)||F` 从存储 B0+S2-J 的原始坐标计算（当前预检约 `0.09517`，正式运行重新计算并记录；若超过 0.4，截断每个 η 到上限 0.6 并报告）。Jacobi 的 δ0 只作为已预注册的修正预算锚点，即使 S2-CG 指标不同也不看结果后改变。固定 η 与 α 的笛卡尔积，**不得按 GT 扩大搜索**。若 S2 在规一化尺度前后不一致，先检查归一化线性等变性，不能修改 δ0。

IC8/IC9 在当前未人工扰动的 G128 上胜出，只能说明“该 IC 正则在当前图上优于二次 S2”；**不能仅凭本轮宣称已经证明对 edge-weight uncertainty 的鲁棒性**。权重扰动稳定性属于后续机制验证，不阻塞本轮超过 B0+S2 的目标。

**数值**：用矩阵自由的 `D`/`Dᵀ` 和 sparse W，采用 P-PDS/PDHG primal-dual splitting。Eq9 保留 `Dᵀ(WDu−p)`，不得代为 Huber 或 squared norm。每个配置保存 cost、primal feasibility、stationarity/prox residual、step sizes 和日志。若欠收敛尝试**同一目标**的数值容差/迭代上限重算一次（不调 α,η）；仍不达标标记 NONCONVERGED，不能进入排序。

### IC9-G（二维几何适配；无额外局部尺度）

`X,U∈R^{N×2}`, `P∈R^{m×2}`, `Q=WDU−P`：

```
min_{U,P} α Σ_e ||P[e,:]||₂ + β ||Dᵀ Q||_F
s.t. ||U−X||_F ≤ η ||X−mean(X)||_F
```

**没有分轴 box**，采用二维观测球来获得旋转/反射等变性，成本变化明确记录。这仍保留 IC9 的全图跨边耦合。旋转、反射、平移、等比例缩放测试是 **必过**，不能用 paper model 的分轴结果来要求这些性质。

## 5. Framelet Node-only（必须保留的论文基础与几何消融）

定义 `D_G=diag(deg_W)`，其中 `deg_W` **明确取原始 G128 加权邻接 W 的行和**（不要与 edge incidence D 混淆）；Framelet spectral operator 使用同一 W 构造的 symmetric normalized Laplacian `L_sym=I−D_G^{-1/2}WD_G^{-1/2}`。所有 `deg_W>0`；连通图的主零模态是 `v₀=D_G^{1/2}1`，满足 `L_sym v₀=0`，通常不是普通常数向量 `1`。若实际图有多个连通分量，则分别使用各分量上的 `D_G^{1/2}1_component` 检查零模态。使用作者仓库 `utils.py::get_operator` 的滤波器 `cos(ξ/2), sin(ξ/2)`，`Lev=2, dilation s=2, n=2`（作者默认，代表一阶 Chebyshev 近似）开始；如 Framelet 数值 gate 不通过，只能为逼近精度增加阶数并记录。在 full-N 必须使用 **matrix-free Chebyshev**；禁止 dense eigendecomposition 或显式 dense `N×N`。analysis 与 adjoint 必须严格互为伴随；原 S2 的未归一化 `L=DᵀWD` 只用作 S2 和 IC，它仍满足 `L1=0`，不要与 `L_sym` 的零模态混用。

**有效 Framelet bands 固定为作者实际调用口径**：`get_operator()` 虽生成每个尺度的低通/高通中间矩阵，但最终 analysis 不能使用全部 `2×Lev` 个返回矩阵。对 `Lev=2`、`DFilters=[low, high]`，作者 `d_list` 顺序为 `[T_low,1, T_low,2, T_high,1, T_high,2]`，本轮固定 `active_bands=d_list[Lev-1:] = [T_low,2, T_high,1, T_high,2]`。`T_low,1` 只作为构造第二尺度算子的递推中间量，不进入最终 analysis、Q 变量、adjoint、reconstruction 或 U-step 求和。manifest 必须保存 active band 名称、顺序与 Chebyshev 阶数。

**最终低通实现不得省略**：ADMM splitting 必须包含有效列表中的 `T_low,2` 与 `T_high,1/T_high,2`。按照作者 `NodeDenoisingADMM`，最终低通的正则权重 `ν_0=0`，表示“参与 analysis、reconstruction 和 `Q_0=T_low,2 U` 约束，但不做 shrinkage”，不是从 active bands 删除。

**U-step 一律精确解当前离散目标**：P1 和正式实验统一用 PCG 求解

`(D_G + ρ Σ_{b∈active_bands} T_bᵀT_b) U = RHS`

（若目标整体归一化导致相同常数缩放，代码与 manifest 必须写出实际等价系统）。`tight-frame reconstruction error≤0.02` 仅是滤波器近似质量 gate，**不得**据此将算子和替换为 I。本轮不启用 `D_G+ρI` 闭式简化；未来若要启用，必须另设更严格的 `ΣT_bᵀT_b−I` 算子误差门槛，并在独立小图上与 PCG/reference U-step 达到相同解精度后重新授权。

### FN-P（paper node-only Eq15）

```
min_U 0.5 Σ_i d_i ||U_i−X_i||₂²
       + ν Σ_{h in highpass} c_h Σ_i d_i ( |(T_h U)_{i,1}| + |(T_h U)_{i,2}| )
```

其中最终低通 `T_low,2` 的正则系数为 0，但仍按上一段进入完整算子约束；高通 `c_h` 参考作者 `NodeDenoisingADMM` 的逐尺度 `1,1/4`。若代码约定方向不同，以 `denoising_filters.py` 为准并在 manifest 写出 `active_bands=[low2,high1,high2]` 的实际顺序。目标项统一按下一段的 per-degree/per-band 约定归一化；ADMM U-step 必须用 PCG 解包含三个 active bands 的系统，不得静默删除最终低通、加入中间低通或套用 tight-frame 闭式近似。

### FN-G（仅二维 group shrinkage 改动）

```
min_U 0.5 Σ_i d_i ||U_i−X_i||₂²
       + ν Σ_{h in highpass} c_h Σ_i d_i ||(T_h U)_i||₂
```

除 x/y 联合收缩外，其余 fidelity、framelet 变换、正则强度、图完全一致。**这是本轮唯一 Framelet geometry adaptation。**

**所有 FN/SD 目标的固定归一化**：令 `d_sum=Σ_i d_i`，`c_sum=Σ_{h∈highpass}c_h`。fidelity 写为 `0.5/d_sum·Σ_i d_i||U_i−X_i||²`；Framelet 正则写为 `ν/(d_sum·c_sum)·Σ_h c_hΣ_i d_i φ((T_hU)_i)`，FN-P 的 `φ(v)=|v_1|+|v_2|`，FN-G 的 `φ(v)=||v||₂`。ADMM 可整体等比例缩放，但保存的 objective/ν 必须对应这个定义；不得一处用求和、一处用均值。

**ν 与公平比较（GT-free）**：先对 B0 FN-P，按 ν 对实际移动量 `δ=||U−X||F/||X−mean X||F` 做 bracket/bisect（每目标最多 8 次，范围只按修正量拓展），定位 `0.5δ0, δ0, 1.5δ0` 三个 target并冻结 `ν_P`。随后对 FN-G 做两种配对：

- `FN-G-ν`：直接复用相同 `ν_P`，回答只改变系数 norm 后目标函数发生什么；报告实际 δ，但不单独据此宣称几何适配更优。
- `FN-G-δ`：用同样无标签 bracket/bisect 得到 `ν_G`，使实际 δ 对应同三个 target；这是 FN-G vs FN-P 的**主要公平性能比较和 G3 gate 输入**。

不同 Chart 只复用 B0 已冻结的 `ν_P`/`ν_G`，不再 bracket。不许拿 GT 指标选择 ν。

## 6. Framelet Edge：必须执行的原文机制和**唯一**条件性 full-N 适配

### 6.1 必做小图原式 self-expression / Edge denoiser / DoT（不作 full-N global ranking）

- 使用两种固定采样：`512`、`1024` 点；每个样本保存原 full graph indices。选择连续时间块和分散抽样的两种方式（各自重建**仅用于 pilot**的局部图/Framelet）；不将 pilot 的 512/1024 结果同 full-N 的 20,997 指标相比较。
- `SEF-P-small`：固定 `U=X`，按 Eq.(5) 更新 S/E，只作为 self-expression 结构拟合诊断。验证 `U−SU−E`、diag(S)=0、S sparsity/row sum 实际表现；计算 learned S 与原无线 support 的重合率（GT-free），以及是否明显用任意节点重心拟合二维坐标。**该项没有输出 denoised U，不进入 Channel Chart 性能表，也不称 Edge denoiser。**
- `FE-P-small`：按论文 Edge denoising ablation Eq.(17) 同时更新 U/S/E，保留 `diag(S)=0, U=SU+E, S1=1` 与 fidelity。为避免作者分类代码中未使用/隐含参数造成歧义，本轮 paper control 冻结 `λ₁=1, λ₂=1`；ADMM penalty (`μ₁,μ₃,μ₄,ρ`) 只作为数值参数按 residual 收敛，不把作者默认 3 次迭代当作收敛。
- `DoT-P-small`：原 Eq.(6) 同数据，完整 node+edge 联合 ADMM；Framelet 使用 B0 已冻结的 `ν_P(mid)` 与完整低通/高通算子，冻结 `λ₁=1, λ₂=1`，从而与 FE-P-small 只增加 Framelet 项。比较 `FNode-small`、`FE-P-small` 和 `FullDoT-small` 的 objective/约束/数值状态及相同小图内部离线 GT 评价。对 FE/DoT 各跑 **2 个确定性初始化**（作者默认与 S0 先验初始化）评估非凸稳定性；记录全部数字，不夸称全局最优。
- 小图中，原论文的 `S1=1, diag(S)=0` 与作者的 `||S||₁` 保留。**如果添加 S≥0 会导致 `||S||₁=1` 每行恒定，绝不添加再声称 L1 促进稀疏**。
- Edge gate 不能仅看 `||U−SU||` 变小：SEF 只判断结构拟合是否退化；真正进入几何 gate 的是 FE-P-small/DoT-P-small 输出 U。还需要结构图有差异、非凸输出稳定且 DoT 相对于 `FNode-small` 与 `FE-P-small` 有独立收益信号（见第 7/8 节）。

### 6.2 条件性全量方法 `SD-Joint`（我们改造的 Sparse DoT）

若 6.1 的 gate 通过，在**相同 full-N G128** 上构造一个有向候选 support `C`：每行取 G128 中权重最大的 `k_C=16` 个非自身邻居；同分 tie 根据 node index 固定。定义先验 `S0_ij∝ W_ij`（行归一化）。所有行保证至少 1 个邻居。学习 `S` 仅有 `N×16` 变量，而非 `N×N`。

**改造目标，不是作者 Eq6 原式**：

```
min_{U,S,E}  [0.5/d_sum] Σ_i d_i ||U_i−X_i||₂²
            + [ν/(d_sum c_sum)] Σ_{h in highpass} c_h Σ_i d_i ||(T_h U)_i||₂
            + [γ/d_sum] Σ_i d_i ||E_i||₂
            + [ξ/(2N)] Σ_i Σ_{j in C(i)} (S_ij−S0_ij)²/(S0_ij+1e−3)
subject to E_i = U_i − Σ_{j in C(i)} S_ij U_j,
           S_ij ≥ 0, Σ_j S_ij=1, S_ii=0, supp(S)⊆C.
```

解释：保留原 DoT 的**节点 Framelet + 自表达残差 + 图关系变量**核心结构；但出于无线场景与可辨识性，显式限制 CSI/geodesic 邻居 support、将 dense 稀疏 `||S||₁` 换成 anchoring quadratic。在 simplex 上 `||S||₁` 恒定，不能留作稀疏正则。此方案通过 `S0` 防止二维重心表示任意拟合；更偏向优化无线候选**边权**而非虚构全新拓扑。`S` 变化不进入 Framelet 图 T_h（首轮固定图以便区分机制），仅进入自表达约束。

**必须实现三组相同系数的配对消融**：

- `SD-Edge`：令 `ν=0`，其余 γ, ξ, C 保留；仅关系学习 + fidelity + 残差。
- `SD-Fixed`：将 `S=S0` 冻结，仍使用 group Framelet、残差与 fidelity；比较与 `SD-Joint` 得到 **是否需要学习边权** 的贡献。
- `SD-Joint`：同样 ν, γ, ξ、固定 T_h 和 C，只让 S 可学习。三组保持相同输入、求解精度和运动预算；不能仅挑 Joint 最好的 γ, ξ 和 Fixed 的默认 γ, ξ 做不公平比较。

**参数固定**：`ν=ν_G(mid)`（FN-G-δ 在 B0 的无标签 `δ≈δ0` 档），`γ∈{0.02,0.1}`、`ξ∈{0.1,1.0}`，严格用于上面已经写明除数的 normalized objective；full-N B0 为 `2×2×3=12` 组，不额外在 GT 上调整。若四种 γ/ξ 都导致同一量级以上的 graph drift/collapse，完整记录并 STOP Edge branch，不扩范围。`ν=0` 的 SD-Edge 没有 Framelet 项，其作用自由度与 SD-Fixed/Joint 不同，必须按消融解释。

**优化**：交替 block coordinate；固定 S 的 U 子问题是凸（含 group framelet、group residual），采用 PDHG/ADMM + PCG；固定 U 的 S 子问题是带 simplex 约束的凸问题（quadratic prior + norm residual），用小行的 projected/proximal-gradient 或 CVXPY rowwise reference；整体非凸，保存每轮 objective，单调性和 stationarity，最多 30 outer epochs，每个 inner solver 按 residual 收敛。最小 2 种确定性初始化（`S0`、valid perturbed simplex），比较稳定性。GPU 4GB 显存限制只允许 sparse `N×16` 表示；不得创建 full `N×N` S。

**特别的可靠性检查**：使用无线原图 support 的 signed/unsigned overlap、`mean_i ||S_i−S0_i||1`、self-expression residual、S 行熵、去除了多少接近零的原边权，以及 GT-free 的邻居几何变形。原坐标 GT 仅在全部固定后离线评价。不允许宣称学到 `S` 就等于发现真实物理边；若 `SD-Joint` 只是比 Fixed 更好重建训练 chart 却不改善 KS/Mean/P95，记为 no evidence of benefit。

## 7. 数学/工程 Sanity Gate：不通过则不得浪费 full-N

### Gate G0 — 数据与 baseline（硬阻塞）

- `N=20997`、三份 `indices/positions` 逐元素相同，finite、embedding 标准差非零；缓存真实来源 hash、图构建一致；`G128` 的 `DᵀWD` 与 CSR Laplacian matvec 相对误差 `<1e-6`（float64），`L 1` 最大绝对 `<1e-8`。
- 同一旧 Jacobi 200 用保存的 B0 初始图重算：KS absolute diff `≤2e-4`，Mean abs diff `≤2e-3 m`，P95 abs diff `≤3e-3 m`；若不通过诊断后停止，不要修改历史脚本凑结果。`S2-CG` 只是同一二次目标的共轭梯度数值控制（不是 Robust-IC/Framelet 论文方法），线性系统 relative residual `≤1e-7`，单列报告与 Jacobi200 的 raw/指标差。

### Gate G1 — 合成图与公式一致性（硬阻塞）

- 16/32/64-node 可控图，使用 CVXPY（或独立等价凸 reference）比较 IC8-P、IC9-P、IC9-G、FN-P、FN-G-ν/FN-G-δ 共用的 group objective 和 feasibility。相对 objective gap `≤1e-3`、归一化可行性误差 `≤1e-4`、最优条件残差 `≤5e-3`；若参考解失败先排除 solver reference 误差再决定 blocker。
- IC8 的解析 Huber equality 在随机梯度上 `atol≤1e-8`（double precision）；IC9 **不能**被替换为 Huber；IC9 的 `Dᵀ` adjoint test `<1e-8`。
- FN framelet `⟨T x,y⟩≈⟨x,T* y⟩` 的相对偏差 `<1e-6`（float64）。先检查全部 degree 为正；对 `v₀=D_G^{1/2}1`（多分量时逐分量）要求 `||L_sym v₀||₂/||v₀||₂ <1e-8`，并以此主零模态检查 `T_high,1/T_high,2` 的 `||T_h v₀||₂/||v₀||₂ ≤0.02`。普通常数向量 `1` 的 `L_sym`/高通响应仅作为辅助诊断保存，**不参与 PASS/FAIL**。使用且仅使用 `active_bands=[T_low,2,T_high,1,T_high,2]` 做 analysis/reconstruction，随机探针相对误差 `≤0.02`；核验 `ν_low,2=0` 但 `Q_low,2=T_low,2U` 约束存在，并核验 `T_low,1` 未混入 active bands。`n=2` 失败只表示近似阶数不足；依次提高到 3…12，记录满足全部 Framelet 数值 gate 的**最小 n**。如 n=12 仍不满足才停止 FN/DoT 分支。
- FN ADMM 的 primal/dual normalized residual 均 `<1e-3`；每次 U-step 都用 PCG 解 `D_G+ρΣ_{b∈active_bands}T_bᵀT_b`，relative linear residual `<1e-5`；必须与小图 reference U-step 和 objective 接近。`reconstruction error≤0.02` 不能授权 `D_G+ρI` 简化。
- `IC9-G`、`FN-G-ν`、`FN-G-δ` 的旋转/反射/平移/各向同性尺度等变性：输入变换后反变换输出 RMS 差/原输出中心化 RMS `<1e-3`。`IC9-P`/`FN-P` 逐轴处理，不强求旋转等变。
- SEF-P-small 核验 Eq.(5) 的 `diag(S)=0`，不要求 row sum，且不产生 denoised U；FE-P-small/DoT-P-small 核验 `diag(S)=0, S1=1, U=SU+E`，相应 constraint residual `≤1e-3`。若 FE/DoT 非凸多初始化出现重大数值发散，记录并 STOP Edge branch，不影响 IC/FNode。
- **零解/伪收益检测**：`ν=0` 且无其他正则时应返回输入 U≈X；`η=0` 的 IC 应返回 X；所有方法 `||U−X||` 非零的配置必须伴随有意义的 finite objective 下降。`S0` 冻结和允许更新 S 应当得到不同解（如真为零差则解释而非当作学习成功）。

### Gate G2 — Full-N 非标签正常性（硬阻塞）

每个新配置须满足：finite、节点索引不变、目标没有持续恶化、图保真与约束满足、没有伪收敛；最终约束残差 `≤1e-3`，IC ball violation `≤1e-4` (相对)，每个 method 的 exit code/status 明确。不能以“达到 200 次”代替收敛。出图时不存在全部节点坍到一点（中心化 RMS ≥ 输入的 0.05，且非有限/同一点比例 <0.1%）；若被约束球允许巨大位移/压缩但图谱明显坍缩，标记 `DEGENERATE` 不入有效排名。每方法记录 `δ=||U-X||F/||X−mean X||F`、normalized/unnormalized output、用时、最大 RAM/VRAM。

### Gate G3 — B0 性能早停（**研究筛选，不是数学失败**）

在三个冻结修正预算 × 冻结的参数组**全部跑完且收敛**后，对 B0 full-N 共同指标评价。先保留两个不同问题的 baseline 名称：`S2-J` 是导师实际 Jacobi200 pipeline；`S2-CG` 是同一二次目标的收敛数值控制。

- **`ADVISOR_HIT`**：相对 `S2-J`，KS/Mean/P95 中至少两项改善 **≥1%**，第三项不恶化超过 **1%**。它只表示超过当前导师实现。
- **进入其它 Chart 的 `SURVIVOR`**：同一配置必须相对 `S2-J` **和** `S2-CG` 分别满足：至少一项改善 **≥1%**，另外两项均不恶化超过 **2%**。这样避免把 Jacobi 未充分收敛误写为新正则收益；若只过 S2-J，则标记 `SOLVER_LEVEL_GAIN_ONLY`，不扩 G1 charts。
- **`TARGET_HIT`**：相对 `S2-J` 和 `S2-CG` 均至少两项改善 **≥1%**，第三项不恶化超过 **1%**。仅作为继续预算投入的筛选条件，最终仍需多个种子/跨数据证据。
- **整条方法家族所有配置均不满足 SURVIVOR**：标记 `NO_GO_EXPLORATORY`，该家族**不再**跑 G1-Identity/G1-Graph 或新的 full-N 改造；保留完整 B0 对比、求解日志和失败分析。不得临时扩 α/η/ν。
- 如果 B0 **没有任何方法**达到 SURVIVOR，结束整轮 full-N 扩展，交付完整负结果；不自动开展随机图重构或新训练。
- 对 `IC9-G` 与 `IC9-P`，按同一 α/η 和实际 δ 配对报告；对 Framelet 同时报告 `FN-G-ν` 的 same-ν 目标消融及 `FN-G-δ` vs FN-P 的 matched-δ 主比较。不得只比各自单独的 GT 最优点。

### Gate G4 — Edge 机制/增量判断（**条件分支**）

原式 small Edge/DoT 的硬数值 gate（G1）通过后，**只有同时满足以下条件才允许编写 `SD-*` full-N**：

1. 512、1024 两种规模均得到有限、稳定的论文 Eq.(17) `FE-P-small` / Eq.(6) `DoT-P-small` 结果，两个初始化没有相差巨大的输出（归一化 chart centered RMS 差 `<0.10`，否则 `UNSTABLE`）；Eq.(5) `SEF-P-small` 只提供结构退化证据，不代替这一条件；
2. `DoT-P-small` 相对 `FNode-small` **和** Eq.(17) `FE-P-small` 分别在同一 pilot、同一评价协议的 KS/Mean/P95 中**至少一项改善 ≥1%**，其它两项不恶化 `>3%`，且不能仅来自极端异常点；否则没有证据说明联合 node+edge 比任一单独分支更值得 full-N 投入；
3. 学得的 S 并非只是由任意远处节点组成的重心插值：报告与无线图 support 的相交比例、外部系数质量、是否近似全零/均匀/完全退化。若此项不满足，停止 Edge 分支。

若任一项不通过，保留 `SEF-P-small`、`FE-P-small` 和 `DoT-P-small` 的真实结果；**不允许**再开 full-N 稀疏 DoT。若全部通过，继续 `SD-Edge/Fixed/Joint` 的 B0 全量实验，再按 G3 同时对照 S2-J、S2-CG 和 `SD-Fixed`；`SD-Joint` 必须展示相对固定 S 的明确增量，才允许扩展两份 G1 charts。

**注意**：G4 小图表现只能决定是否值得投入算力，不构成 full-N 改进与否的科学结论。必要时做两种采样 sanity，而不是把 512 点排名当成全图排名。

## 9. 不能替代的数据/论文解释

- `IC8/IC9` 的论文原始任务是图信号恢复，换成二维 Chart 观测即转用；选择 G128 也是项目图，不是作者使用的合成图。**不要把跨实验 GT 得到的 top-1 当成保留的泛化性能，也不要把当前图上的性能提升直接写成已证明 edge-weight uncertainty robustness。**

- 如果只比 `B0+S2` 好 0.001m 但别的指标差，必须如实显示，不包装成稳定显著提升。
