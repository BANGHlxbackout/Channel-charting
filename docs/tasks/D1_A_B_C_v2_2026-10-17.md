## 2. 数据、图与算子：所有方法共用

### 2.1 输入身份与已有代码

- 复用 `common_dichasus.load_data1` 的真实 CSI `(N,4,8,13)` complex64；`run_adp_siamese.AdpFeatureLayer` 输出 26,624 维；G1 `feature_cache` 应通过随机逐行 allclose 与原 layer 对齐。保留跨阵列相位/功率的已有同 tap 自相关特征，不重做预处理。
- 从 Stage-1 距离 run 的 `distance_data.npz['indices']`、`fused.npy`、`geodesic.npy`、`result.json` 重建原 kNN 有向图；按 G1 的 32-source shortest-path audit 与 `geodesic.npy` 比较，报告 `max_abs_diff/mismatch_count`。本轮 `geodesic.npy` 允许**仅 v2 地标/中远程负样本采样**和图身份验证使用；A/B/C 不许把 `D_geo` 用作损失或训练目标。
- 共用 G1 `propagation_adjacency` 的 symmetric affinity 定义和保留的无向 support（不重新调 k、kernel、图来源）。保留原始 fused 有向 shortest-path cost，与用于扩散的 affinity 严格区别。

### 2.2 明确三个不同矩阵

1. **`W`：无自环、对称、非负局部 affinity**。从现有 G1 的无向 support / local-scale kernel 重建，记录边数和权重分布。
2. **`P = D^{-1}W`：行随机游走转移矩阵**。`d_i=sum_j W_ij`；`π_i=d_i/sum d`；验证 `P1=1`、`πP=π`、`π_iP_ij=π_jP_ji`。若存在零度节点，停止并报告，不静默修图。
3. **`A_hat=D_tilde^{-1/2}(W+I)D_tilde^{-1/2}`：网络 GCN 的稀疏传播矩阵**。`Identity` 模式使用同尺寸单位矩阵 `I`。`A_hat` 一般不行随机，严禁拿它直接采样 walk 或计算 B 的 `PZ`。

A/B/C/v2 共用完全同一个 `W/P/π/A_hat` 图源。Graph/Identity 的网络参数量、采样与训练预算相同，只切换网络传播邻接；**Identity 的训练损失仍然使用真实图 P**，它不是无图监督模型。

图边的 ADP/timestamp 物理含义不等于真实空间邻近；本轮不把 GT 用于改图或删除疑似短路边。记录连通分量、degree、`π`、t=1,2,4 的回跳率/独立终点数及混合趋势；不可根据 GT 优选时间尺度。

## 3. D1-A：两种完整 N 的无训练谱基线（必须运行）

**研究问题：图算子本身能否恢复有效二维几何，而不依赖 CSI 编码网络？**

- **A0（Laplacian Eigenmaps / diffusion coordinates）**：`W0=W`，`L_sym=I-D^{-1/2}W0 D^{-1/2}`；稀疏 `eigsh` 求至少 8 个最小特征对。对单连通图跳过平凡模态，将第 2、3 个非平凡模态由 `u_k/sqrt(d_i)` 转为随机游走右特征向量，再按预先冻结的 diffusion time `t=1` 乘 `(1-λ_k)^t` 形成二维嵌入；最终中心化、全局等比例 scale 到坐标 RMS=√2。
- **A1（density-corrected diffusion maps）**：固定 `W1_ij=W_ij/(d_i d_j)`，其中 `d` 为原 W 度；重新构造新度和 `L_sym`，其余 eigen embedding、t=1、中心化/尺度和 A0 相同。
- 若图不连通，先如实报告组件/零模态；不得通过任意跨组件拼接坐标伪造整体二维图。特征向量固有符号和二维旋转不影响统一仿射评价，保存谱残差、eigengap、输出实数和随机初始化种子。
- 严禁 dense NxN Laplacian/eigh。A0/A1 都要输出独立 embedding、metadata、Chart、同一统一评价，不得只报告较好的版本。
- **理论定位**：A 是图数据直接恢复空间几何的无参数参照，不是新的神经网络 Loss；A 的表现不决定是否取消 B/C/v2。

## 4. D1-B：论文 Position Diffusion 的严格非坍缩版（两组 full-N 必跑）

原论文 Jin et al. (2026), Eq. (12) 的核心是 `||PZ-Z||^2`。对行随机 `P`，常数 Z 是零损失；**不将未约束的纯 PD loss 当作有效正式模型**。先做常数解的合成数学测试，再采用下述约束模型。

设 `Π=diag(π)`，对网络输出 `Z_θ ∈ R^(N×2)` 进行**每次 full-graph 前向中的可微π-加权中心化和白化**：

\[
\mu=\sum_i\pi_iZ_i,\quad U=Z-\mu,\quad C=U^T\Pi U,\quad \bar Z=U C^{-1/2}.
\]

白化的有效性条件：`C` 两个特征值皆严格大于预设数值阈值（默认 `1e-8`，同时记录相对条件数）；若接近奇异则视作失稳并记录，不许通过巨大 epsilon 强行制造无意义二维输出。以 `\bar Z` 训练和评价：

\[
\boxed{\mathcal L_B=\sum_{i=1}^N\pi_i\|(P\bar Z)_i-\bar Z_i\|_2^2}
\]

它是**带非坍缩正交约束的扩散残差最小化**；仅用图监督，不用 geodesic pair targets。数学性质：对于可逆加权随机游走，平稳分布权重下，该目标与图拉普拉斯低频谱有关，但它与简单 `tr(Z^TLZ)` 不是任意矩阵下的同一个目标。

两组独立随机初始化模型：

- `D1-B-Identity`：GCN 内部邻接 I，Loss 中 P 为真实图。
- `D1-B-Graph`：GCN 内部邻接 A_hat，Loss 中 P 为同一真实图。

两组均 full N、训练最大 2,000 step、同一超参、同一初始随机权重张量、同一无 GT 验证节点覆盖；checkpoint 依赖固定 full-N 或固定无 GT 局部图损失，不读取真实位置。每次保存 `covariance eigenvalues, corr(Zbar), L_PD, Dirichlet energy, val objective, effective rank, output std`。图上训练与验证节点无法严格独立，在记录中注明这是传导式评估。

**B 的重要解释边界**：因白化条件，目标可能主要恢复原图的低频谱空间，和 A 的结果相似；即使 Graph 未超过 Identity，也不代表训练错误。报告 B 与 A 的二维距离结构相关性和综合指标，验证网络是否只是逼近谱基线。

## 5. D1-C：纯多尺度扩散对比几何（两组 full-N 必跑）

**目标：不回归 `D_geo(i,j)`，只让二维坐标描述图扩散在不同尺度的相对可达性。**

固定 `T={1,2,4}`, `K=32`，每步 `4,096` anchors，`i~Uniform(N)`，t 均衡采样，`j+~P^t(i,:)`（逐跳采样，t=2/4 返回起点允许、记录比例）；`j-_k~π`（排除与正样本/anchor 完全相同的 ID，并记录拒绝率，但不根据真实坐标排除）。每个批次使用冻结 RNG 流，Identity/Graph 可复现相同 anchor/positive/negative 序列。

以全图输出中心化并等比例归一化：

\[
U_i=\frac{Z_i-\operatorname{mean}_j Z_j}{\sqrt{N^{-1}\sum_j\|Z_j-\operatorname{mean}Z\|^2/2}}.
\]

分母过小即明确标记 collapse，不能靠 eps 掩盖。固定温度 `τ_1=0.2,τ_2=0.4,τ_4=0.8`，score `s_t(i,j)=-||U_i-U_j||²/τ_t`，定义：

\[
\boxed{\mathcal L_C=\mathbb E\left[\log\left(e^{s(i,j^+)}+\sum_{k=1}^{32}e^{s(i,j^-_k)}\right)-s(i,j^+)\right]}
\]

代码必须使用 `logsumexp`，绝不直接指数求和。常数图谱基准 loss 为 `log(33)`；在合成局部图上应检查存在低于常数基准的非坍缩解，但不能认为这数学上排除所有退化驻点。对 C 监控 full-N 两轴方差、有效秩、节点距离分位数和 local neighbor crowding。

独立训练：`D1-C-Identity`、`D1-C-Graph`。除网络邻接外参数、初始化 tensor、pair streams/temperature/training budget/validation 规则相同。**不得加载旧 G1 二维 chart 或使用 `D_geo` 生成 C 的训练正负样本。**

## 6. D1-v2：扩散主目标 + 中远程关系 + 无监督全局约束（两组 full-N 必跑）

**目标：在 C 的局部多尺度扩散基础上，额外约束中远程相对几何，防止纯局部对比导致整体折叠。** 训练从独立随机新网络开始。

### 6.1 v2 的 contrastive 主目标

使用 C **同一正样本流、时间尺度、温度、anchor**，但 `K=32` 负样本划分：前 16 个来自 C 所用的 `π` 背景流，其余 16 个来自对应 anchor 的 `D_geo` **60%–95% 行内正距离 rank 区间**（无标签中远程 hard negatives）。除严格相同节点/正样本 ID 外不按 GT 过滤。不能将图 geodesic 距离解释为真实物理距离。

- 中远程 sampling 以 CPU `geodesic.npy` mmap 完成，预处理按 row 分块得到 60%、95% 阈值，保存有版本和 seed 的采样元数据；不可在 GPU 建 dense NxN，禁止为每 step 对整行反复 sort。
- 分布采样差异是 v2 与 C 的**第二个变量**；因此 `v2 vs C` 比较的是**整体方法组合收益**，不能直接称为地标约束的单独增益。若 v2 优于 C，再做下一轮独立无 shape 消融。不能为求消融提前扩张本轮 6 组训练。

### 6.2 landmark log distance-ratio constraint

在不看 `UE_pos` 的条件下，仅根据 `D_geo` 选择 `M=64` 个覆盖图测地距离的 landmarks：第一个 ID 由 seed 决定，后续最远点贪心 FPS，保存 IDs/hash。构建固定且分开的 shape `train`、`dual-control`、`validation` 三元组集合 `(i,a,b)`：均匀 i，a/b 从 landmarks 中采样且图测地距离处于不同分位、非零且非 self。三组数据的抽样 RNG 相互独立，Graph/Identity 共用。

对非退化 Z 定义：

\[
\Delta_{iab}(Z)=\log\frac{\|Z_i-Z_a\|}{\|Z_i-Z_b\|}-\log\frac{D_{geo}(i,a)}{D_{geo}(i,b)},
\qquad
\boxed{\mathcal L_{shape}=\operatorname{mean}\operatorname{Huber}_{0.5}(\Delta_{iab})}.
\]

使用数值相对下限（随全图 RMS 等比例缩放）仅处理机器精度，近零图谱必须报 collapse；Huber 和距离比具有旋转/平移/统一缩放不变性。不可把真实米制误差用来设定约束。

### 6.3 **只用图谱 A 校准 v2 约束阈值**，不依赖已有 G1 权重和输出

**此处明确取代旧 D1-v2 文档的阈值构造方式**：

1. 先运行 D1-A0 和 A1，并在固定 shape-train 三元组上计算两者 `L_shape`（不使用 GT）。
2. 固定无标签参考 `A_ref=argmin_{A0,A1} L_shape(A on shape-train)`；保存两个数、选择规则、参考版本。**这个选择仅用于定义无监督 proxy threshold，不替代 A0/A1 的 GT 报告，也不作为网络训练权重/标签/初始 embedding。**
3. 冻结 `b=1.20 × L_shape(A_ref on shape-train)`（统一一个 b，Graph/Identity 完全相同）；另计算 A_ref 在 shape validation 上的 loss 供诊断。若 `L_shape(A_ref)` 几乎 0 或 threshold 引发数值问题，报告并停止，不偷偷改 b。
4. 严格说明：b 是**图上代理几何可行性标准**，不是 GT 坐标约束，也不保证 Mean/P95 一定改善。使用 A 的 graph-only 指标设 b，不等于继承已训练网络。

### 6.4 约束求解与随机初始化训练

优化问题：

\[
\boxed{\min_{\theta}\ \mathcal L_{diff}(Z_\theta)\quad\text{s.t.}\quad\mathcal L_{shape}(Z_\theta)\le b}.
\]

训练使用增广拉格朗日/对偶变量，无 Geo Stress：

\[
\mathcal J=\mathcal L_{diff}+\lambda (\mathcal L_{shape}-b)+\tfrac\rho2[\max(0,\mathcal L_{shape}-b)]^2,
\quad \lambda\ge0.
\]

冻结默认 `ρ=10, λ_0=0, η_dual=1, λ_max=100`；原始主候选不人工加回 Geo Stress。Dual 仅根据**独立的 dual-control triplets** 更新，真正的 shape-validation triplets 仅用于 checkpoint 检查；必须测试违规时乘子上升及可行时回退、梯度稳定。

**从随机初始化开始的数值可行性**：若初始网络没有满足 b，不允许加载任何现有模型。训练从第 1 步开始使用上述约束优化，固定 full-N 2000-step 上限；在短 Pilot 评估梯度、dual 轨迹、约束可达性。如果长期全不满足条件，结果记录为 **constraint infeasible / optimization failure**，保留 log 和最后 checkpoint；不得事后根据 GT 放宽 b 或切换 Geo Stress。若想尝试其它 b，则必须另立单独新版本并先审阅，不能把修改后的结果并进当前预注册组。

Checkpoint：先选 `L_shape_validation ≤ b`、输出 finite 且非坍缩的候选；在可行候选中取 `L_diff_validation` 最低；若没有可行 checkpoint，**不得**按 GT 最佳或偷偷按扩散损失选择“成功”模型。保存 last 和最低 violation checkpoint 作诊断，明确 `no_feasible_checkpoint`，不能把它排进成功主排名。报告 feasible rate 与全程 violation 曲线。

## 7. 统一的训练/验证、随机性与算力协议

- 六个训练组都 `N=20,997`、新模型参数由相同 seed=10 的初始化得到（各自独立实例、相同参数 tensor 初值）、`hidden=512`、`num_layers=2`、`dropout=0.1`、全图 sparse GCN、`AdamW(lr=1e-3, weight_decay=1e-5)`、warmup 100 step + cosine decay 到 1e-5、`max_steps=2000`、`grad_clip=5`。v2 同一 2000 总预算，包括约束优化；不要把旧针对继续训练的 600-step/1e-4 参数带来。这里 learning-rate warmup 是从零新模型的学习率调度，不是继承模型权重。
- D1-B 每 step 完整图扩散残差；C/v2 每 step 4096 anchor，32 negatives。三者单步 loss 计算量不同，必须分别报告实际 GPU hours；统一 step 数仅是训练预算的首要控制，**不能声称三目标计算成本严格相同**。
- 验证：训练前分别冻结 (i) 对 C/v2 共用的验证 anchors、walk t/positive、negative 基础流，(ii) v2 的 shape-control/shape-validation，(iii) B 的固定 full-graph 无 GT 验证目标。所有验证采样 seed 单独派生，不得从随机 unordered pair key 排序前缀截取验证集。验证目标是图训练关系上的**独立随机样本，而非 held-out 节点/区域泛化**。
- 每 20 step validation，连续 12 次无改善可早停；B/C 以其固定验证 objective 最优且 non-collapse 的 checkpoint 选取，v2 用独立可行条件 + diffusion validation 最优；同一 loss 内 Identity/Graph 完全相同的验证集合和 early stop 规则。报告实际 best_step/steps 与验证曲线。
- 全图 float32 26,624 维 cache 使用 CPU memmap + GPU 分块 Linear + torch checkpoint recomputation（保持可微梯度）及完整图 BatchNorm，不将整张 `D_geo`/稀疏图 dense NxN 放 GPU。继承已有 G1 数值等价测试和 features/graph cache 数据身份验证。
- 所有版本保存训练前随机初始参数 fingerprint、first sampled batch hash、validation stream hash、graph hash、参数量与实际环境。图传播的身份对照须保证仅 adj 不同；v2 与 C 因负样本/约束不同，报告为**方法组合比较**。
- 若正式训练资源不足，先完成全部数学测试、A0/A1、每组短 pilot，记录六组训练时间和 GPU 资源预测，再向用户说明预计的总成本/阻断；不得偷缩 full-N 到 stride-10、把短跑称为正式结果，亦不得因此略掉某个规定组而声称任务全部完成。

## 8. 必须通过的测试与执行顺序

### 8.1 单元/数值测试

1. **旧 G1 数据身份**：indices 完全一致、cache ACF 与旧 `AdpFeatureLayer` 一致、图 support/k/32 源最短路审计、GPU 分块 projector 的 output 与 gradients 对齐。
2. **图随机游走算子**：W 对称无自环、P 行随机/π平稳/detailed balance；合成有向/无向小图步行频率和 P^t 相符；A_hat 与 P 严格区分；合法零距离边不能丢失。
3. **D1-A**：L_sym 对称、谱残差小、平凡模态辨认与符号不变性；密度校正后 degrees/π 正确；全量 eigsh 有限、无 dense NxN。
4. **D1-B**：常数图谱使未约束 PD≈0；非退化白化后 `weighted mean≈0, weighted covariance≈I`；2×2 eig inverse sqrt 可微；rank collapse 被报告而不静默继续；等价谱小图对照。
5. **D1-C**：常数输出 InfoNCE≈log(33)；合成图中存在更优非坍缩结构；温度/尺度正常；Graph/Identity loss 正负样本一致。
6. **D1-v2**：landmarks FPS 决定性、不同 rank 采样符合预设、train/dual-control/validation 互不重叠且索引覆盖；shape ratio 对平移/旋转/等比例缩放保持不变；b 只从 A 的无 GT 值产生；dual 更新符号与 step 正确；全不可行时标记结果而非伪造成功。
7. **验证分布**：避开旧 G1 验证 pair 的低索引采样偏置，随机节点/三元组覆盖全 N，训练和验证 RNG 隔离；验证节点不等于未见节点。
8. **目标优化 sanity**：每一损失在小图有有限非零梯度、模型输出不坍缩、存储/恢复新模型保持数值一致；`eval()` 下 checkpoint 预测确定。

### 8.2 固定执行顺序

1. **Read-only preflight**：读 AGENTS，检查数据/图/索引/资源/GPU；审计源图、W/P/π。记录目录和版本。
2. **合成测试**：A/B/C/v2 全部数值测试通过，缺一不可。
3. **完整 D1-A0/A1**：N=20997，两种谱输出 + 全量无 GT 数值信息；GT 评价统一留到各正式 run 冻结结束之后执行（输出 embedding 可先保存）。
4. **真实 CSI 小样本 sanity + full-N 短 pilot**：六组覆盖 B-I/G、C-I/G、v2-I/G；正确索引配套、finite loss/gradient/BN、完整图传播；不输出 GT 性能以免影响方案选择。
5. **六组 full-N 正式训练**：先 B-I/G，再 C-I/G，最后 v2-I/G。按固定随机初始化与训练协议执行；若 v2 两组完全不可行也必须保留独立训练产物、解释失败，不可伪造可行最优结果。
6. **统一离线评价**：只在运行/模型选择冻结后读取 GT。读取所有 A、B、C、v2 embedding 和旧 B0/G1 embedding，使用共同 `indices`、seed10 的同一 4,199 节点子集算 CT/TW/KS；全部 N 同一原 affine 函数算 Mean/Median/P90/P95/Max。AGENTS.md 规范的 Chart/comparison/REPORT 等完整交付。
7. **科研结论**：针对 RQ-A/B/C/v2、同 loss 传播差异、Stage-1 是否严格胜出 G1 和全局形状是否损坏，填写数字、图和基于数字的下一步决策。**不自动追加 S2、G2、调图、其它训练目标和新种子**。

## 9. 预先冻结的评估门槛与如何阅读两版 loss 的结果

- **最强已知 Stage-1 指标边界**：KS `<0.079340`，Mean `<0.398343 m`，P95 `<0.843197 m`，CT/TW 相对 G1 各自最佳不得下降多于 `0.0003`。须由**同一个 D1 run 同时达成**才称为 *single-seed joint improvement*；允许另外报告部分指标提升，不得换不同方法拼凑一组所谓最佳成绩。
- **直接比较 v1 C 与 v2**：同模式配对（C-I vs v2-I；C-G vs v2-G），看 KS、Mean、P95、P90/Max、CT/TW、visual trajectory、near/mid/far `D_geo` rank 层间失真、shape loss、folding/crowding。v2 好说明**整个局部+全局方法包**可用，**不能单凭本轮断定**是 landmark constraint 还是 hard negatives 带来收益。
- **比较 B 与 A**：如果 B≈A，说明 B 很可能主要在学习图低频谱、神经网络编码未带来明显额外几何质量；如果 B 明显更好，须检查实际 PD Loss 目标、谱模态和训练结果是否一致，而不是立即宣布新物理机制。
- **比较 Graph 与 Identity**：B-G vs B-I，C-G vs C-I，v2-G vs v2-I。仅对同一 loss 同预算比较传播增量；即便 Graph 依赖邻接，也不等于 Graph 比 Identity 更好。无需重复 E2 的“Graph checkpoint 切换 I”实验。
- **几个重要结果组合及判断**：

| 实验现象 | 可支持的初步解释 | 后续工作（待用户/研究 review 决定） |
|---|---|---|
| C 和 v2 都明显超过 G1 | 扩散目标有潜力 | 新 seed、图质量与 loss 消融 |
| C CT/TW 或 KS 改善，但 Mean/P95 变差；v2 恢复 | 中远程关系有助于全局几何保持（整体方法包） | v2 去 shape / 去 hard negatives 的独立消融 |
| C 优于 v2 | 当前全局约束或 hard negatives 可能过强/有误 | 先看 feasibility、形状约束与采样难度 |
| B≈A、C/v2 优于 B | 纯平滑/低频谱不足，区分邻近尺度更重要 | 扩散时间/负采样机制分析 |
| B 明显优于 C/v2 | 图低频几何可能足够，而对比采样有误差 | 谱分析与目标敏感性 |
| Graph≈Identity，但两者都提升 | loss 可能是主要受益因素，传播暂时不是必要组件 | 非图网络也可获得的 loss 改善 |
| 六组都差于 G1 | 新图扩散训练目标尚未优于全局 Geo Stress | 图误差、收敛、非均匀采样与形状代理检查 |
| v2 全不满足约束 | 当前 b / 表达能力 / 求解策略存在可行性冲突 | 先诊断，不借旧权重掩盖问题 |

- 对每一个指标同时输出**绝对差值与相对变化**，报告 Graph/Identity 同 seed 的训练成本、图源 hash、验证 loss、非坍缩统计。当前结果属于 single-seed、same-node transductive；affine 校正使用相同真实坐标拟合与评价，**不是 held-out 定位精度**。
- 不用 GT 选择 epoch/温度/b/最优方法重新训练。即使得到好结果也仍需要后续多种子、消融和新节点泛化评价，不能直接宣称独创论文方法。
