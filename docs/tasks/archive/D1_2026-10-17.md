## 1. 为什么要做 D1？与论文/旧 G1 的精确区分

2026 论文：Jin et al., *Rethinking Channel Charting: A Graph Perspective*, arXiv:2609.06204v1, Section IV, Eq.(8)–(14), https://www.alphaxiv.org/pdf/2609.06204

- 旧 G1 使用 `siamese_loss(Y_i,Y_j,D_geo(i,j),margin)`：使欧氏输出距离回归全局最短路距离。
- 论文 Eq.(12) 提出 `||P Z - Z||_F^2` 类型的 position-diffusion / harmonicity objective，其中 P 为行归一化邻接；Eq.(13) 联系到 Laplacian smoothness。论文实验采用三层 GCNConv、raw complex CSI flatten、ADP 图；我们不是其网络/训练的复现。
- **数学注意**：若 `P 1 = 1`，任意常数输出 `Z=1c^T` 令 Eq.(12)=0，因此纯 loss 存在坍缩全局最小值。`P` 若不是对称矩阵，`|| (I-P)Z ||_F^2 = tr(Z^T (I-P)^T (I-P) Z)`，不能一般性地写成 `tr(Z^T (I-P)^2 Z)`；未约束的 `tr(Z^T L Z)` 同样允许常数解。这些是数学性质，不等于断言论文实际训练必然发生了坍缩。
- D1 不采用“原 geodesic loss + λ×PD 正则”。我们主动提出**不同于原来的、无 `D_geo` target 的两个独立训练目标**：D1-B 的 constrained position diffusion（谱基线）与 D1-C 的 multi-scale diffusion contrastive geometry（主候选）。

核心研究问题：

> G1 的 Graph≈Identity，是因为同源 `D_geo` stress 已包含图约束，使消息传播没有额外优势；还是因为现有 fused 图不适于学习有效二维局部/多尺度几何？改成真正由图扩散定义的训练目标后，Graph 是否会超过 Identity，并且图谱质量是否超过旧 G1 / B0？

## 2. 图算子：区别 GCN 邻接、损失转移矩阵与测地距离

固定真实 N 与样本顺序，严格复用 `graph_utils.check_distance_run`, `rebuild_directed_graph`, `audit_shortest_paths`, `propagation_adjacency` 的图身份、边 support 与已有 kernel 定义。32 个源最短路复验仍执行，作为图身份检查，不把 `D_geo` 当新 loss 的 target。

从 G1 传播用的**无向、非负、对称、无自环边亲和度** `W` 构造：

\[
P_{ij}=W_{ij}/d_i,\quad d_i=\sum_j W_{ij},\qquad
\pi_i=d_i/\sum_jd_j.
\]

`P` 是**行随机游走转移矩阵**：行和=1，`πP=π`，`π_i P_ij = π_j P_ji`（对称原 W）。用于 loss 的随机游走无自环；GCN 传播仍严格沿用原来的加自环、对称归一化 `A_hat`。不要直接将 `A_hat` 当成概率矩阵，它通常不是行随机的。

缓存新算子的 meta（distance-run 身份、seed、k、N、kernel、edge support checksum）；`P`、`π`、edge weights 必须验证非负、有限、归一化、stationary 和 detailed balance。不得用 `1/D_fused` 或用 `D_geo` 代替 affinity。

### 2.1 低成本图源有效性探查（数据诊断，不修改方法）

- 采样 source 节点，比较 k 步随机游走的终点分布、去重到达节点数、近邻复访率、`t=1,2,4,8` 的熵/接近 stationary 程度；不可让过度混合的时间尺度被盲目赋高权重。
- 记录图连通分量、节点 degree / 权重分布、局部尺度 `rho` 的分位数；对少量确有 cross-region shortcut 的边可**用真实坐标在训练结束后做离线诊断**，但不可据此改本轮图。

## 3. D1-A：无神经网络的谱 / Diffusion Maps 基准（先运行）

**目的**：直接检查这张图在不训练深度网络、也不访问 geodesic target 时，究竟含多少可恢复的二维结构。与 G1-Graph/Identity 的新 loss 实验共同回答“图 vs 网络 vs Loss”。

- 用已有 `W` 构建对称标准化图 Laplacian：`L_sym=I-D^{-1/2}WD^{-1/2}`；获取最小的若干特征值/特征向量，舍弃常数/平凡模态，按 normalized Laplacian eigenmaps 映射成二维。（注意多连通分量和接近零本征值，不能误删有效模态。）
- 至少给两个固定的无 GT 版本：`alpha=0`（原 W）和 `alpha=1` 的 density-corrected diffusion map：`W'_ij=W_ij/(d_i d_j)`，再重新归一化；这是既有 Diffusion Maps 思想，不声称独创新。
- 使用 `scipy.sparse.linalg.eigsh` 等稀疏方法；禁止将 `(N,N)` 图转 dense；记录 eigensolver 残差、eigengap、符号/坐标尺度选取。用已有统一评价协议重算指标。
- 保留 `D1-A0` / `D1-A1` 两套结果，即使指标差也不得隐藏。

## 4. D1-B：Constrained Position Diffusion（论文启发的非坍缩版本）

论文式纯项：

\[
L_\mathrm{PD}(Z)=\sum_i\pi_i\|(PZ)_i-Z_i\|_2^2.
\]

**必须实现一个短 Sanity（例如 30–100 step）** 并记录 `std(Z) / eig(covariance)`，展示纯项有常数最优解的理论事实；不要把其坍缩结果写成论文算法实现失败，不必让已知退化训练占用整轮 full-N 资源。

**D1-B 主实验不是原 Loss+罚项，而是一个受约束的图谱优化问题**：

\[
\min_\theta\ \|P\bar Z_\theta-\bar Z_\theta\|_{\Pi,F}^2,
\qquad
\bar Z_\theta^T\Pi\bar Z_\theta=I_2,
\quad \bar Z_\theta^T\pi=0.
\]

其中 `Π=diag(π)`。通过可微**加权中心化与 2×2 whitening / orthonormalization** 满足非坍缩约束（不是新增 geodesic 罚系数）：

```
mu = sum_i pi_i * Z_i
U = Z - mu
C = U.T @ diag(pi) @ U
Zbar = U @ invsqrt(C)      # eigendecomposition 2x2
loss = sum_i pi_i * || (P @ Zbar)_i - Zbar_i ||^2
```

输出评价也使用 `Zbar`；小特征值设 numerical floor 并记录，不得通过 epsilon 掩盖坍缩。显示 `eig(C)`, eigen gap, `||PZ-Z||` 和 Laplacian Dirichlet energy。理论上与非平凡平滑模态密切相关，不保证它能给出真实物理二维坐标；这是需验证的 Baseline。

同一 G1-ACF 模型和参数，两组 full-N：

- `D1-B-Identity`：网络中的 `adj=I`；Loss 中 `P` 仍为真实图（否则 loss 恒为零）。
- `D1-B-Graph`：网络中的 `adj=A_hat`；Loss 中 `P` 仍与上组**相同**。

训练依然只使用 CSI + W/π；不访问 `D_geo` 的 pair target。配套相同种子/预算/early stop 策略，仅改变网络邻接。训练前验证图谱输出在归一化约束下没有数值异常。

## 5. D1-C：Multi-scale Diffusion Contrastive Geometry（主候选）

### 5.1 要解决什么问题

只要求 `PZ≈Z` 让局部曲面变平，却不要求不同位置可分；图谱可能坍缩或被压成错误的形状。

我的更积极的假设是：**物理空间几何不仅体现为邻居均值相似，还体现为从某个 CSI 节点扩散 1、2、4 步时的可到达概率相对整张图平稳分布的偏离。** 如果让二维 Chart 直接编码这些**多尺度可达关系**，就可以避免依赖全局最短路标尺，并通过正负竞争自然抵制坍缩。

### 5.2 完全替换 geodesic 的训练目标

训练图随机游走：

- `i` 从全部 N 节点近似均匀采样，避免只训练密集区域；
- `t` 从预定集合 `T={1,2,4}` 平衡采样；若无 GT 的 mixing 诊断支持 `t=8` 仍携带非平稳信息，可**作为预定义单独扩展实验**添加，不能训练时临时手调选择最优 GT 结果；
- 正样本 `j+ ~ P^t(i,:)`：从 `i` 进行恰好 t 步有权随机游走；
- 负样本 `j-_1,...,j-_K ~ π`，默认 `K=32`；必要时排除恰好相同 node ID 的重复（报告过滤率）；
- `s_t(i,j)=-||z_i-z_j||²/τ_t`，`τ_t>0` 为同一尺度的预设/可训练温度，温度策略需在第一次正式训练前**固定且两模型一致**。建议先用尺度归一化后的 `τ_1=0.2,τ_2=0.4,τ_4=0.8` 作单一固定主配置，不用 GT 优选。

\[
\boxed{L_\mathrm{MDCG}=
\mathbb E_{i,t,j^+,j^-}\left[
-\log\frac{\exp(s_t(i,j^+))}{\exp(s_t(i,j^+))+\sum_{r=1}^{K}\exp(s_t(i,j^-_r))}
\right]}
\]

在二维网络输出上，使用**全 N 的无参等比例中心化与 scale normalization**，解决任意尺度导致温度无意义的问题：`Zc=(Z-mean(Z)) / sqrt(mean_i ||Z_i-mean(Z)||² / 2)`；保留二维各向异性，避免用单位球约束每个节点。若分母过小，记录 collapse failure，禁止悄悄跳过；正则化只为浮点稳定，不加回 Geo loss。

**为什么不是原损失换名字？** 正样本来自 `P^t`、负样本来自 `π`，训练只区分局部/多尺度随机游走到达与图平稳背景。没有目标地理米数、没有 `D_geo(i,j)`、没有 pairwise geodesic regression，也不是原 stress 的加权版。这个目标与已有 diffusion maps / noise-contrastive neighbor embedding 有联系，**不能未检索就声称首创**。

**避免坍缩的理论/数值检验**：当所有节点输出同一坐标时，所有 score 相同，InfoNCE≈`log(K+1)`；在有有效邻近结构的图上，应存在能使期望 InfoNCE 更小的非坍缩表示。这里的 `log(K+1)` 不是阻止所有退化局部驻点的数学保证，仍须监测方差、距离分布和有效 rank。

随机游走 t=2 可能回到 `i`；对 `j+=i` 的特殊样本需要固定规则（建议拒绝/重采终点，记录比例；此时采样的是**条件分布**而非原始 `P^t`，须在报告中明示），或直接保留并分析影响，绝不能两个模式规则不同。建议一律保留 t≥2 的合法返回，排除 t=1 的自环已由 P 无自环保证。

训练建议：`N=20997`，全图 forward，`4096` anchor/step，`K=32`，`2000 step`，`seed=10`，原 G1-ACF 的 26,624 特征与网络结构、数据缓存、GPU 分块投影、优化器、BN/LayerNorm 等不变；相同 validation sampler（仅从图构建、与训练随机状态隔离，不使用 GT）、checkpoint 按 validation MDCG 选择。若理论建模/训练监测需要合理修改数值参数，需在第一组 full-N 前冻结，并在两个模式严格一致。

Full-N 主对照：

- `D1-C-Identity`：**网络内传播邻接=I**，但正/负样本来自真实 `P` / `π`；
- `D1-C-Graph`：网络内传播邻接=`A_hat`，loss 所见的 `P` / `π` 与 Identity 完全相同。

Graph-vs-Identity 才能检验**在新训练目标下**邻居消息传播是否有额外收益。

### 5.3 与物理位置的关系

这里不假定随机游走时间 t 等于实际步行时间，也不假定 t 步对应 t 米。扩散过程是图的几何探针，不是测距。强 timestamp shortcuts、采样密度不均衡、边 affinity 失真可能导致扩散与物理邻近不一致；这正是要通过统一 GT 离线评估和后续图源消融检验的内容。

## 6. 执行顺序与资源决策

**A. 建图+数学测试（CPU）**

- 记录仓库/依赖/CUDA/显存/可用磁盘；对 N=20997 的 fused 图验证数据身份、kNN support、最短路审计、W→P/π 的算子性质；检查随机游走实际步数以及无 GT mixing 统计。
- Synthetic 小图：常数 Z 的纯 PD loss 精确≈0；有局部结构的非坍缩图上 MDCG loss 比常数输入更低；PD-B whitening 非坍缩及 finite gradient；随机游走频率符合 P^t；固定 RNG 的 Graph/Identity 正负样本及网络参数相同，唯邻接不同。
- 若 `P` 不随机、π不平稳、图身份检查失败或不可复现，**停止并汇报错误**，不能偷偷修改图来源。

**B. D1-A 谱基线（完整 N，只需稀疏 eigensolver）**

- 输出两个谱图谱和评价，记录本征值、残差、时间、内存。无 GT 选参。不要由于谱图谱质量差就中止 C。

**C. D1-B 论文式 loss 对照**

- 纯 PD 短 sanity；然后 D1-B Identity/Graph 两组 full-N，保存 best 以及训练日志。确保使用经归一化约束的实际输出评估。

**D. D1-C 独立多尺度扩散对比 loss（本轮主实验）**

- 先 stride-10 或小图 sanity（使用独立、索引匹配的 fused graph）；按 AGENTS 交付 sanity 图但不进入主排名。
- full-N `D1-C-Identity` 与 `D1-C-Graph` 各训练 2000 step（允许按冻结的 validation patience 早停）；训练预算不同则记录真实耗时和变更授权，不通过降采样冒充 full-N。
- 建议优先完整跑 C，若设备资源不够同时完成 B/C，则 B 做谱+短 sanity 后先执行 C 的两模式；在报告中明确未完成内容。单个 full-N 训练最长耗时预计与 G1 相近，额外 loss 算子成本需要现场 Pilot 评估。

**E. 统一比较与下一轮决策**

主比较：`B0`、`G1-Identity-Geo`、`G1-Graph-Geo`、`D1-A0/A1`、`D1-B-Identity/Graph`（若已完成）、`D1-C-Identity/Graph`。保持一致 indices 与 evaluation subset，测 CT/TW/KS、Mean/Median/P90/P95/Max。绘图、`comparison/` 和汇报格式严格遵守 `AGENTS.md`。

如果 `D1-C` 比旧 G1 更好，记录提升发生在哪些区域/距离分位/极端值，且检查与 B0+S2 的差距；如果 C 只提升 KS 而误差变差，明确 mixed；如果 C 不如 B0，不隐瞒负结果。

关键因果辨别：

| 观察结果 | 暂时支持的解释 | 下一轮选择（先上层审阅） |
|---|---|---|
| D1-A 很差，B/C 都差 | 原 fused 图的扩散结构可能难恢复二维几何 | 图源/关系质量诊断（ADP vs timestamp） |
| D1-A 差，C 明显更好 | 非线性 CSI 编码能改善单纯谱嵌入 | 继续查证 C 的学习机制和稳健性 |
| C-Graph ≫ C-Identity | 图传播在新目标下提供额外增量 | 多种子、后处理和输入敏感性，再考虑 G2 |
| C-Graph ≈ C-Identity，但都更好 | loss 有价值，传播仍不关键 | 优先研究 loss 与非图网络，而非堆叠 GNN |
| B 明显优于 C | 低频谱/调和几何更适合本数据 | 研究谱算子与频率选择 |
| C 训练无法区分正负，或 collapse | 负样本/混合时间尺度设计不成立 | 诊断 sampled positives / negatives / temperature，重设计再跑 |

不得把单 seed + 同数据仿射评价直接写成泛化结论、论文创新，或凭 GT 选择下一组超参数后当成无偏验证。必要的多种子独立复验作为后续正式阶段。
